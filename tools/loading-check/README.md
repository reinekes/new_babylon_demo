# Диагностика загрузки

Отдельный тестовый город: строгий Южный Шумер,«Взрослый бог»,seed137,пауза. Autosave и настройки панелей живут только в памяти страницы; библиотека IndexedDB отключена. Обычные index.html/app.js и личные сохранения не меняются.

Генерация из текущего checkout: `node scripts/prepare-loading-browser-check.mjs`. Запуск: `tools/loading-check/index.html?run=УНИКАЛЬНЫЙ_КЛЮЧ`. Сетевой снимок виден в `#loading-report`; кнопка обновляет его и радиус камеры для проверки настоящего zoom.

Это лабораторный full-app тест с новыми ключами same-origin запросов,а не очистка кеша браузера и не Lighthouse. Сохраняются module/model версии,данные файлов и параллелизм загрузчиков. CSS-копии сохраняют @import и меняют ключи шрифтов/фактур; UI-иконки,вставленные исходным шаблоном,могут оставаться кешированными и видны в zeroTransferRequests. При повторе static CSS dependencies используют прежний ключ выпуска; всегда проверяй фактический transferSize,а не слово«cold»в имени.

`appReady` — завершение исходного app-модуля с готовыми обработчиками,`firstFrame` — первый завершённый renderer.draw после него,`detailsReady` — существующее обещание основной очереди подробного города/фауны. Последнее не обещает загрузить все необязательные функции. Проверяй UI-контрол отдельно. Штампы относительно navigation timeOrigin,в мс; localhost не характеризует сеть Pages.

В Resource Timing transferSize — браузерный учёт с условной добавкой300байт,не точный размер сетевых пакетов. Для body-count требуются transferSize>300 и encodedBodySize>0,чтобы не принять revalidation-only за получение тела; нулевые/кешированные записи сохранены. Отдельно записаны encoded/decoded body sizes и навигационный HTML. Суммы относятся к записанным запросам,не ко всему диску игры. [Спецификация W3C](https://www.w3.org/TR/resource-timing/).

Метрики paint/LCP/longtask собираются лишь при поддержке браузера. `layoutShiftSum` — сырая сумма без session window,не CLS. Не выдаём INP/SpeedIndex/оценку Lighthouse. Панель,инструментированный app и принудительные ключи добавляют измерительный overhead; это не немодифицированная навигация на главную игру.

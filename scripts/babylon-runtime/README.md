# Babylon и сетки дальних жителей

Сайт использует готовые файлы в репозитории. GitHub Pages может отдавать их напрямую.

После изменения списка модулей или обновления исходных моделей:

```sh
npm ci --prefix scripts/babylon-runtime
npm run build --prefix scripts/babylon-runtime
npm run build:resident-lod --prefix scripts/babylon-runtime
```

`entry.mjs` задаёт API Babylon для города, квартала, двора и студий. В комплект входит загрузчик glTF 2.0. Лицензия Babylon лежит рядом с результатом в `assets/vendor/BABYLON-LICENSE.txt`. Полные vendor-файлы используются тестовыми сценами и как дополнение для окружений с уже подключённым движком без загрузчика GLB.

Генератор LOD берёт треугольники из пяти существующих моделей и сохраняет только новые индексы. Он записывает отпечаток исходного GLB, чтобы другая версия модели продолжала использовать полную геометрию. Цвет, веса костей и прочие атрибуты вершин берутся из исходного меша.

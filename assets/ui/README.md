# Night Uruk interface assets

Mineral textures and bronze seal generated with OpenAI ImageGen on 2026-11-04 for the user-selected interface concept. Original PNGs remain local; published WebP copies preserve the generated image content with compression. Basalt, fired clay and lapis are artistic UI interpretations, not archaeological reconstructions.

Lora and Golos Text: Google Fonts, SIL Open Font License; licenses in fonts/. Locally hosted Cyrillic/Latin subsets downloaded via https://fonts.googleapis.com/ on 2026-11-04. Phosphor regular icons: @phosphor-icons/core 2.1.1, MIT; license in icons/. Source https://github.com/phosphor-icons/core and pinned https://unpkg.com/@phosphor-icons/core@2.1.1/assets/regular/.

Historical material inspiration: https://www.metmuseum.org/art/collection/search/324023 (Sumerian bronze, shell and lapis ornament, Early Dynastic III). The existing simulation and 3D assets are unchanged.

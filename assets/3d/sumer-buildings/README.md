# Постройки Южного Шумера

В [игровой студии](../../../scripts/sumer-building-studio.html) можно выбрать любую из 45 моделей и скачать её GLB. В [дорожной карте](../../../roadmap/#buildings) рядом показаны старые и новые виды, проверка в городе и пять эскизов будущих построек. Для локального просмотра запустите `npm start` в корне проекта.

Выпуск включает 40 типов из строительного каталога, дома II и III, стартовый улей старого сценария, временный тростниковый шалаш и дорогу. У жилищ самостоятельные модели с общими фактурами глины, тростника, дерева, керамики и ткани. В мастерских видны их оборудование и утварь. В городе поле следует береговой линии, пролёт моста зависит от реки, а канал стыкуется с соседними участками. Файлы для скачивания фиксируют по одному варианту такой геометрии.

Материалы и игровые прототипы описаны в [атрибуции](../ATTRIBUTION.md). Исходники домов находятся [в каталоге авторской серии](../studies/house-level-1-earth/). Предложенные объекты хранятся [отдельно](../proposed-buildings/).

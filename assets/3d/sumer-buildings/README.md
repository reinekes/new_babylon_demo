# Постройки Южного Шумера

40 моделей GLB с материалами и встроенными текстурами. Имена файлов совпадают с типами из строительного каталога. В комплект входят все 39 построек исходной галереи и караульный двор из актуальной версии.

[Открыть тестовый город и выбрать постройку](../../../scripts/sumer-building-studio.html). Для локальной копии запустите `npm start` и откройте `/scripts/sumer-building-studio.html`. Стенд использует игровой WebGL-рендерер.

Модели выгружены из локальных координат игровых мешей, с центром участка по X/Z. GLB фиксирует один видимый вариант I уровня. Игра собирает рабочие зоны, уровни, состояние посевов и запасов залежей, пролёт моста и примыкания канала в зависимости от состояния города. Поэтому мост и канал в комплекте показывают конкретные участки реки, а ограды и растительность добывающих дворов могут меняться. Лесорубная площадка включает деревья и может выходить кронами за край клеток.

В основе комплекта — процедурная геометрия игры и ранее подключённые прототипы. Для этой серии переработаны дом I, хлебная и кирпичная печи, добавлены общие формы утвари для родственных производств и детали добывающих дворов. Материалы заимствованы из самой игры. Условия повторного использования исходных материалов см. в [атрибуции проекта](../ATTRIBUTION.md).

# Панель развития игры · 3 ноября 2026

Статус: выполняется по прямому запросу пользователя на готовый HTML и редактируемые Markdown-источники.

## Устройство

`plan.md` содержит только незавершённые задачи со стабильными ID. `reports/*.md` — датированные отчёты и исторические выпуски. `historical-review.md` — проверка новых замечаний. `overview.md` — порядок этапов. `build.py` проверяет источники и собирает переносимый `index.html`; HTML содержит снимок всех данных и работает без сервера. При HTTP-открытии он также может перечитать Markdown по сгенерированному `manifest.json`.

Отметки в браузере — локальный черновик. Экспорт создаёт ZIP с планом без выбранных задач и новым датированным отчётом; оригинальные Markdown автоматически не перезаписываются. Отметка владельца отличается от подтверждения публикации. `ОБНОВИТЬ.command` повторяет сборку без установки библиотек.

- [x] Создать локальные отметки и экспорт обновления; проверить сохранность зависимостей и отсутствие молчаливого редактирования MD.
- [x] Проверить загрузку с HTTP и file://, мобильный вид, семантические контролы и локальные ссылки и сценарий следующего отчёта.

## Пределы

Игровой код, сохранения и личные материалы не меняются. Старые подтверждения публикаций показываются как сведения документов, без заявления о новой проверке сайта. Нет общего «процента готовности всей игры». Новые исторические замечания не считаются выполненными только от наличия строки в плане.

Проверено: 5 Python + 4 Node/jsdom; реальный ZIP прочитан zipfile и повторно проверен валидатором. HTTP — ручная проверка; file:// — исполнение jsdom; 390px — браузерная проверка. Проверка клавиатурной навигации ограничена семантическими контролами и CSS-фокусом, отдельного полного прохода нет.

# Атлас 3D-моделей

Из корня проекта запустите `python3 -m http.server 8114 --bind 127.0.0.1` и откройте [Атлас](http://127.0.0.1:8114/model-atlas/). Папка работает и на статическом хостинге при публикации вместе с остальным проектом.

Здания берутся из `definitions.js`, а геометрия — из производственных генераторов. Клетки с тире означают отсутствие уровня. Стартовый дом и дорога показаны отдельными строками. Переключатель меняет профиль зданий и модели, которые от него зависят. Образцы процедурной геометрии изолированы от остального ландшафта.

«Здания», «Животные» и «Мини-модели» имеют собственные URL и файлы данных в `model-atlas/data/`. «Мини-модели» включают людей, транспорт, растения, предметы и мифологические скульптуры. Поиск и статусы действуют в текущей вкладке. Маршруты `?model=` и `?species=` используют небольшую карту ссылок, чтобы открыть нужную вкладку и карточку.

Команда `node scripts/model-index.mjs` обновляет общий индекс GLB и файлы вкладок. `node scripts/model-index.mjs --check` проверяет их согласованность с моделями и кодом. Превью GLB показывает исходный файл. Игровые костюмы, груз и рабочие позы могут добавляться кодом в городской сцене. Анимации в окне просмотра берутся из выбранного GLB.

Превью создаются по мере прокрутки на одном canvas. Каждый вид модели подключает свой рендерер по мере необходимости.

«В игре» показывает основные модели. «Резерв» объединяет запасные файлы и подмену при ошибке загрузки. «Отдельные сцены» показывает модели студий. Поиск работает в выбранной вкладке.

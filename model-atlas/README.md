# Атлас 3D-моделей

Из корня проекта запустите `python3 -m http.server 8114 --bind 127.0.0.1` и откройте [Атлас](http://127.0.0.1:8114/model-atlas/). Папка работает и на статическом хостинге при публикации вместе с остальным проектом.

Здания берутся из `definitions.js`, а геометрия — из производственных генераторов. Клетки с тире означают отсутствие уровня. Стартовый дом и дорога показаны отдельными строками. Переключатель меняет профиль зданий и модели, которые от него зависят. Образцы процедурной геометрии изолированы от остального ландшафта.

`docs/model-index.json` даёт список GLB, статус и происхождение каждого файла. Превью GLB показывает файл без игровых костюмов, груза и привязки к сцене. Анимации в окне просмотра берутся из выбранного GLB. Процедурные сцены и основные модели предметов представлены отдельно. Составные состояния, частицы, все сочетания нарядов и расстановки декора не являются отдельными файлами.

Превью создаются по мере прокрутки на одном canvas. Игра и сохранения не загружаются.

# Новый Вавилон — полный остаток обсуждённых задач

Дата сверки: **27 октября 2026**. Основа аудита — игровой коммит `c3e8537` и последующее отдельное уточнение о непрерывной музыке/близком литофоне. Это список состояния, **не разрешение внедрить все идеи сразу**.

## Как читать список

- **Долг / частично:** прямая просьба ещё не закрыта полностью.
- **Согласованное направление R:** исследование 19 октября пользователь одобрил словами «давай делать это всё по шагам»; крупный дальнейший этап требует отдельного ограниченного плана.
- **Концепция G / идеи I:** пользователь просил придумать и описать. Для списка из 36 идей прямо было сказано «НЕ ДЕЛАЙ». Написанные концепции уже выполнены как документы; их будущие функции пока не внедрены.
- **Открытое решение / финализация:** вариант обсуждался, но не выбран, либо остался материал для окончательной сборки.
- **Есть:** строка включена только для сверки старого каталога; повторно делать её не надо.

**S01–S35 — основные связанные направления. B01–B48, A01–A12, E01–E48 и 36 идей — перекрёстные каталоги, а не ещё 144 независимых долга.** Например наставник, место ученичества, обращение «Передать ремесло» и история стареющего мастера относятся к одной системе.

## 13. Десктоп и выпуск в Steam — обсуждали, не сделали

Главный чат 19 октября: пользователь спросил о десктопе из-за тормозов, получил поэтапный путь и согласился начать с диагностики. **Оптимизация браузера началась, но десктоп/Steam не выпускались.** Выбор Electron/Godot не был разрешением немедленно переписать всю игру.

1. Отдельная десктопная сборка/установщик и проверка её локального хранения.
2. Настройки и восстановление для приложения, несколько слотов сохранений и резервные копии. Нынешний один localStorage-save и защитный backup миграции не являются менеджером слотов.
3. Пробная передача нескольким новым игрокам, понятность без наших объяснений, разные компьютеры.
4. Страница Steam, трейлер, финальные скриншоты и распространяемая сборка.
5. Steam-достижения и облачные сохранения, если выбран этот выпуск.
6. Проверенный состав ассетов для такого распространения и приложение обещанных разрешений (раздел2).

Цель первого шага — плавная игра на имеющемся компьютере; упаковка сама по себе D01 не закрывает. Godot был альтернативой после профилирования, не выбранным переносом. Аккаунты, платные API и сетевой режим в прототип не входили.

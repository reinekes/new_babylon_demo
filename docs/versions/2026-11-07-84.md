Номер завершённой постройки сохраняется в счётчике города. После сноса новый дом по тому же адресу получает новый номер даже в тот же игровой момент. Семейная память остаётся у прежней постройки. В старом городе первый новый номер учитывает живые здания и номера из семейного архива. Старые записи сохраняют свои даты. Связь погребений с домами засвидетельствована в Ниппуре, счётчик игровой. [Раскопки Ниппура](https://isac.uchicago.edu/sites/default/files/uploads/shared/docs/oip78.pdf)

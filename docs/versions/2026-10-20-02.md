# 20 октября 2026 · Первый 3D-квартал

Выпуск: `district3d-20261020-1`. Сохранения основной игры остаются v22.

Новая отдельная страница `district3d.html`, ссылка «3D-квартал» из основной игры. Babylon.js9.31.0, локальный движок и четыре набора фототекстур CC0. Полный перечень источников/лицензий — assets/3d/ATTRIBUTION.md.

Реализованы объёмные дворовые дома/мастерские/поля/мост и прочие типы зданий, реальный ландшафт/река/озёра/дороги, пальмы/прибрежная трава. Процедурные люди/звери двигаются по существующей симуляции; грузы, возраст, одежда и занятия различимы. Фигуры за камерой пропускают анимацию; статичная архитектура объединена по материалам и заморожена.

Камера вращается/приближает, доступны пауза/1×/4×, выбор дома/человека, день/закат/ночь, заселённые тёплые дворы, лёгкая графика, PNG и скрытие панелей. Показательный квартал — настоящий тестовый город; режим «Копия моего города» читает основное сохранение без записи. Сам3D-сеанс не сохраняется, строительство выполняется в основной игре. Это первый художественно-технический срез, не завершённая графика уровня Banished и не полный перенос интерфейса.

История: [PennMuseum о городской жизни](https://www.penn.museum/sites/expedition/mesopotamian-city-life/), [материалы поселений](https://www.penn.museum/sites/expedition/adaptation-and-change/). Сырцовый кирпич/тростник уместны; конкретные фасады, масштаб и растительность — художественная модель. Средневековая архитектура из референса не копируется.

Проверки: 457/457 тестов, отдельное ревью и исправления, реальный браузер день/ночь/390px/выбор/PNG; сохранение основного города неизменно. Файлы игровых механик не переписаны. Разработческий прогон `?benchmark=1` включает синтетический город200 жителей на4× и автоматически пропускает события только в этом тестовом режиме; обычная копия ждёт решения игрока.

CPU симуляции 129 зданий/200+ жителей4×: медиана1,90 / p955,44мс, максимум102,67мс; 15 циклов encode/decode прошли. Это CPU без растеризации; FPS отдельно фиксируется по браузерной сцене. Движок8,2МБ и текстуры5,6МБ загружаются только на отдельной3D-странице.

Публикация, коммит и итоговая браузерная нагрузка будут дописаны после приёмки.

Браузерная нагрузка в одном окне:129 зданий/209 жителей4×, симуляция продолжалась (контроль simTime234,3→402,7). Контрольные двухсекундные окна: высокая89FPS/CPUкадраp9512,6мс; лёгкая119FPS/8,8мс. Время суток и число видимых фигур различались, поэтому это не прямое сравнение режимов. На другом устройстве результат может отличаться.

# 2026-11-13 · Подборка моделей животных

Выпуск `supplied-fauna-20261113`, коммит `98ffed02`.

- На берегу появились три обыкновенных перепела. Для местной квакши используется приближённый образ с анимацией прыжка из GLB. Зимний пеликан использует новую модель на воде и прежнюю геометрию при посадке и взлёте.
- В 3D-атласе доступны все 16 карточек. Три GLB работают в игре, десять доступны в резерве. Три модели под лицензиями с ограничением NC открываются в 3D у авторов. Каждая карточка содержит источник и пояснение.
- Присутствие перепела и пеликана подтверждают современные наблюдения в южном Ираке. Их появление и число птиц в игре являются реконструкцией. Дикие онагры сохранены. [Перечень ЮНЕСКО](https://whc.unesco.org/document/169034) · [Исследование кунг](https://pmc.ncbi.nlm.nih.gov/articles/PMC8759742/)
- Прошли 29 профильных тестов. Chrome WebGL подтвердил модели в сцене и сезонные переходы пеликана. Полный обзор при 200 жителях и 129 зданиях на 4× дал 18,4 FPS в диагностическом прогоне. Двадцать файлов сверены с GitHub Pages.

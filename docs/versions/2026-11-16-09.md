# 2026-11-16 · Большой рынок

Выпуск `market-2x2-20261116`, игровой коммит `da69a89d`.

- Новый рынок занимает четыре сухие клетки. В 3D загружается GLB с шестью навесами, товарами и двором с двумя открытыми входами. Модель содержит 7 971 треугольник и 14 встроенных текстур. 2D и 3D без GLB показывают размер площадки. Сохранённые рынки на одной клетке продолжают работать на исходном месте.

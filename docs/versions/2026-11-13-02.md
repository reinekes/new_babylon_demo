# 2026-11-13 · Разбор тростниковых шалашей и стройплощадки

Выпуск `camp-salvage-20261113`, коммит `c22721b4`.

- Когда жильцы переезжают из временного тростникового шалаша и уходят с участка, укрытие превращается в связку тростника. Четыре единицы тростника вывозятся обычной перевозкой. Если нет доступного склада со свободным местом, груз ждёт. После доставки клетка освобождается.
- Новая стройка начинается с размеченной площадки. Материалы появляются по мере доставки, кладка и настил моста по мере выполнения работ. Полноразмерные леса убраны в 2D и 3D.
- Кирпич и учёт работ подтверждены для Ура III. Леса прежнего вида были игровой реконструкцией. Возврат четырёх единиц тростника является игровым балансом. [Университет Гамбурга](https://www.csmc.uni-hamburg.de/publications/mesopotamia/2024-03-24.html)
- Прошли 42 профильных теста, включая загрузку сохранения с тростником в руках носильщика. Десять файлов сверены на GitHub Pages. Chrome WebGL показал 20,64 FPS на 4× при 200 жителях и 129 зданиях в диагностической сцене. Цель 30 FPS в этом прогоне не достигнута.
- На публичной версии Chrome подтвердил низкую стартовую площадку, доставку четырёх единиц и освобождение клетки.

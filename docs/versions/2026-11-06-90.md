«Откровение» теперь можно открыть через одну завершённую стройку. Два разных ученика должны по очереди поработать вместе с одним мастером. Обзор показывает три отдельных рассказа, карточка стройки — ход обучения. Старые свидетельства о дорогах с полуклеточными координатами загружаются.

Прошли 1720 тестов. Chrome подтвердил блокировку при одном ученике и три рассказа после завершения. На 4× в городе со 133 зданиями и 289 жителями состав бригад и материалы заданы в фикстуре, работу выполнила симуляция. Сохранение совпало побайтно, вне нового журнала состояние совпало с контролем. CPU шага — медиана 3,48 мс, p95 13,80 мс. [Замер 4×](../benchmarks/2026-11-06-revelation-apprentices-4x.json)

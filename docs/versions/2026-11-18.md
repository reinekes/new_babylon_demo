# 2026-11-18 · Сырцовый дом I уровня

Выпуск `earth-house-20261118-1`, игровой коммит `4ce7b38b`.

- Обычный дом I уровня получил текстурированную модель с тростниковым навесом, двором и наружной лестницей. Она применяется к существующим домам, новому строительству и предпросмотру размещения. Дом сохраняет свой облик до завершения улучшения на II уровень.
- Городской GLB содержит 8246 треугольников, шесть материалов и 12 встроенных карт. Размер файла 1 325 556 байт. Город, атлас и студия используют одну модель. Обновлена иллюстрация в справочнике.
- Прошли 54 профильных теста. Локальная проверка Chrome WebGL подтвердила обычное строительство, материалы модели, переходы I–III и побайтное восстановление сохранения. [Кадр из города](../../roadmap/evidence/2026-11-18/earth-house-level-one.webp).
- В городе с 500 жителями и 250 зданиями одновременно загружены 208 домов I уровня. На скорости 4× общий план показал 28,97–29,75 FPS при исходных 28,42, крупный план — 47,62 FPS при исходных 46,24. Это замеры кадров Chrome на Apple M5. [Отчёт замеров](../benchmarks/2026-11-18-house-level-1-earth-4x.json).
- GitHub Pages опубликовал игровой коммит. Девять публичных файлов, включая GLB, совпали с ним по SHA-256. [Выпуск на GitHub Pages](https://github.com/reinekes/new_babylon_demo/actions/runs/44267812811).
- Публичный Chrome с отключённым кэшем загрузил все материалы дома, построил новый дом и проверил улучшения до III уровня; ошибок выполнения не было.

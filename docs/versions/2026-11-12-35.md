# 2026-11-12 · Круги на воде при кормлении крякв

- Выпуск `mallard-ripples-20261112`, коммит `eb8f286e`.
- При касании клювом воды у каждой птицы расходятся два тонких кольца. Они остаются в точке касания и постепенно затухают. [Сцена в игре](https://reinekes.github.io/new_babylon_demo/mallards.html?v=mallard-ripples-20261112)
- Кормление и присутствие вида у шумерского поселения реконструированы по современной экологии. Круги на воде переданы игровым эффектом. [Наблюдения в Южном Ираке](https://onlinelibrary.wiley.com/doi/10.1155/2017/4198690)
- Прошли 17 профильных тестов и сверка индекса моделей. Эффект просмотрен в Chrome WebGL. Полный обзор на 4× при 200 жителях и 129 зданиях показал 33,63 FPS на Apple M2 без ошибок очереди загрузки.
- GitHub Pages подтвердил развёртывание, четыре публичных файла сверены с выпуском.

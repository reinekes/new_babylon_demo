# 2026-11-12 · Малая белая цапля на мелководье

- Выпуск `little-egret-20261112`, коммит `98728f89`.
- Цапля стоит на мелководье, осматривает воду и периодически делает короткий бросок клювом. Модель с белым оперением, чёрными ногами и жёлтыми пальцами открывается в разделе «Птицы». [Модель в 3D](https://reinekes.github.io/new_babylon_demo/model-atlas/?species=egret)
- Присутствие вида реконструировано по современным наблюдениям в Южном Ираке. [Полевое исследование](https://doi.org/10.1155/2017/4198690)
- Прошли 29 профильных тестов. В Chrome WebGL проверены птица у реки и опубликованное превью. Полный обзор на 4× с 200 жителями и 129 зданиями показал 34,14 FPS на Apple M2 без ошибок очереди загрузки.
- Семь публичных файлов GitHub Pages совпали с выпуском.

# 2026-11-11 · Птицы на берегу

- Выпуск `uruk-shore-birds-20261111-4`, коммит `dc67baa`.
- Стая у поселения снижается к свободному сухому берегу. Птицы садятся на отдельные места, складывают крылья и снова взлетают. Цикл привязан к игровому времени.
- Болотные птицы засвидетельствованы для Южного Шумера. Конкретная форма стаи и цикл посадки условны. [Исследование болот Южного Шумера](https://research.uniroma1.it/en/pubblicazioni/26918)

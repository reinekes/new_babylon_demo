Карта без берега для рыбалки показывает причину недоступности «Богатого улова» в карточке и обзоре. Текущие генераторы создают долины с рекой, поэтому отсутствие берега проверено на отдельной тестовой карте. На существующих рыболовных участках отдых сохраняет заряды до реального улова или смены сезона.

Прошли 1679 тестов. Chrome показал причину и шесть зарядов после загрузки города с двумя закрытыми участками. На 4× город со 129 зданиями вырос с 200 до 221 жителя. Первый улов после открытия участка списал ровно один заряд. CPU шага — медиана 2,07 мс, p95 5,97 мс.

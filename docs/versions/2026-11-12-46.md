# 2026-11-12 · Гладкошёрстная выдра

- Выпуск `smooth-coated-otter-20261112`, коммит `fc10a621`.
- Выдра плывёт по свободному участку реки, гребёт лапами, ныряет и выныривает дальше по маршруту. У модели тёмная шерсть и светлое горло. [Посмотреть в 3D](https://reinekes.github.io/new_babylon_demo/model-atlas/?species=otter)
- Присутствие вида в древней сцене реконструировано по современным наблюдениям в болотах Южного Ирака. [Полевое исследование](https://iucnosgbull.org/Volume30/AlSheikhly_Nadar_2013.html) · [Описание окраса](https://www.nature.com/articles/srep41611)
- Прошли 29 профильных тестов. В Chrome WebGL проверены выдра в реке и опубликованное превью. Полный обзор на 4× с 200 жителями и 129 зданиями показал 33,61 FPS на Apple M2 без ошибок очереди загрузки.
- Семь публичных файлов GitHub Pages совпали с выпуском.

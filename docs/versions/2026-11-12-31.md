# 2026-11-12 · Пара крякв у берега

- Выпуск `shore-mallard-pair-20261112`, коммит `9e6d4ca2`.
- Самка Microsoft с добавленным клипом покоя стоит на сухом берегу рядом с селезнем. Масштаб селезня исправлен. В атласе обе птицы доступны во вкладке «В игре».
- Кряква наблюдается на зимовке в современных Центральных болотах Ирака. Для Шумера размещение реконструировано по среде. [Полевое исследование](https://onlinelibrary.wiley.com/doi/10.1155/2017/4198690)
- Прошли 17 профильных тестов и сверка индекса моделей. Chrome WebGL показал обеих птиц у воды и клип `Idle` в атласе. Полный обзор на 4× при 200 жителях и 129 зданиях дал 22,52 FPS на Apple M2 при параллельном запуске тестов, ошибок очереди загрузки нет.
- GitHub Pages подтвердил развёртывание. Восемь файлов сверены по SHA-256, публичное превью самки с анимацией проверено в браузере.

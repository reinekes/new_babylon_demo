# 27 ноября · Семейный ужин и доставка после разлива

Выпуск `dinner-first-20261127`. Игровой коммит `65a3fafb8560333515585937a36ca0ca519405f2`.

Склад оставляет запас на ближайший ужин другим семьям, прежде чем пополнить кладовую впрок. Пустого заблокированного носильщика можно подменить на том же заказе. При критическом голоде доступна настоящая порция дома, в грузе или у источника. Для семейной поставки сохраняются адрес, полученный остаток и точное количество съеденного. Разовый срок ожидания учитывает физически погруженную еду и проходимость дороги после разлива.

| Проверка | Результат |
|---|---|
| Копия №169, 24 ужина | 40 → 0 смертей от голода, 93 жителя из 99 живы, 6 умерли от старости |
| Копия №170, 24 ужина | 0 → 0 смертей от голода, 74 жителя из 77 живы, 3 умерли от старости |
| Обеспеченный город | 6 полных ужинов подряд для всех жителей, родился ребёнок |
| Совместимость | 3 текущих сохранения и 20 архивных из версий v1–v27 прошли загрузку и повторное сохранение |
| Автоматические проверки | Снабжение 57/57, полный набор 2332/2335. Три сбоя воспроизводятся в предыдущей версии |
| Нагрузка на движок | 500 жителей, 250 зданий, 4×. Медиана 4,35–4,40 → 4,36–4,39 мс, P95 7,80–8,13 → 7,95–8,59 мс |

В Chrome на исходной копии №170 окно «Снабжение семей» показало, что в дома ещё нужно доставить 58,4 единицы, в пищевых дворах готовы 124,8. В этом состоянии у 41 жителя был пропущен ужин. При открытии окна ошибок JavaScript не возникло. На последнем из 24 последующих ужинов полную порцию получили 36 из 74.

# План художественного двора

Согласованный объём: docs/ART_COURTYARD_SPEC.md. Исполнение в текущем чате; источники людей/овцы/пальмы проверяются независимыми агентами, код сцены и интеграция — основной агент.

1. Получить модели, проверить лицензии/геометрию/скелеты/клипы; выбрать пригодные основы.
2. Через изолированный Blender подготовить GLB, материалы/масштаб/одежду/клипы, сохранить скрипты конвертации и источники.
3. Собрать отдельную сцену courtyard.html с освещением, двором, растительностью, камерой, переключением анимаций/качества и измерениями; добавить ссылку из3D-квартала.
4. Проверить бинарные файлы/ссылки/изолированность сохранений, визуально проверить в браузере, выполнить нагрузку200 фигур4× и подходящие прежние тесты.
5. Опубликовать проверенную пробу наPages; сверить контрольные суммы, снять реальную сцену, создать датированную версию. Качество остаётся предметом оценки пользователя.

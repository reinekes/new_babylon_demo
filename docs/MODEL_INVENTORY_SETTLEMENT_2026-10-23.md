# Дополнение инвентаризации · поселение и жители · 2026-10-23

Предыдущий полный список45GLB сохранён в [инвентаризации цветущей долины](MODEL_INVENTORY_2026-10-23.md). В текущем каталоге **48GLB**; три новых файла и изменённый взрослый перечислены ниже. Авторство/лицензии не меняются при адаптации; точные размеры/SHA256 — в assets/art-courtyard/manifest.json.

| Название | Использование | Источник и изменения |
|---|---|---|
| `sumer-people.glb` | Взрослые жители | Trident.AI / прежний CC0rig: цельные волосы, очищенная кожа головы, исправленные оси рук; лица/ID/грузы сохраняются |
| `sumer-child.glb` | Дети до10лет | Производная того же разрешённого исходника: реальные детские вершины/суставы/bind/translation-клипы, простая одежда; не uniform-scale взрослого |
| `sumer-adolescent.glb` | Возраст10–15лет | Отдельные подростковые пропорции, переход роста к взрослому |
| `sky-bird-single.glb` | По одной настоящей птице на каждый летающий actor | Zacxophone / Standard, прежнее подтверждённое разрешение; одна исходная птица, правильный перед, только авторские вращения крыльев |
| `imported-sky-birds.glb` | Исходный адаптированный пакет сохранён для происхождения/сравнения | В основной игре вместо него используются отдельные нормализованные птицы |

| Название | Использование |

# World64 rivers and awakening Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development; tasks share explicit file ownership.

**Goal:** Новые безопасные карты64×64 с ориентированными реками, разными озёрами и следующими шагами Пробуждения.
**Architecture:** Размеры и версия генератора хранятся в world; прежние значения по умолчанию40×32. Река задаётся в локальной системе along/across, которая преобразуется в мировые X/Y.
**Tech Stack:** JavaScript ES modules, Babylon.js9.31, node:test/NullEngine.
**Spec:** docs/superpowers/specs/2026-11-02-world64-design.md

## Global Constraints

Старые сохранения не расширять/не перегенерировать. Личности и грузы сохранять. CPU не называть FPS. Новые модели/музыку не скачивать. Пробуждение — существующие правила, новая подсказка.

## Review Focus

- Старые40×32 и v1 загружаются точно; новые клетки >40/32 работают и сохраняются.
- Горизонтальные реки: мосты, лодки, водоносы, торговцы и реликвии используют ту же географию.
- Оба направления течения видны в воде; лодка приходит с правильного края и уходит.
- Озёра связны, разнообразны; старт не затоплен, припасы и берег доступны.
- Размер карты не размножает чрезмерно геометрию; большой город4× и геометрические счётчики проверены.

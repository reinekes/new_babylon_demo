# Поселение, жители и труд — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Выполнить запрос пользователя: пять стартовых домов-ульев с запасами внутри; разные дома II–III; разнесённая размножающаяся фауна и правильный полёт; естественные взрослые/дети; реальные контакты работников с оборудованием.

**Architecture:** Симуляция хранит только долговременные данные: тип стартового дома и развитие популяций. Рендер читает состояние, имеет отдельные модели/позы/точки контакта. Старые сохранения мигрируют без пересоздания города, жителей, складов и грузов. Новая игра меняется отдельно от миграции.

**Tech Stack:** ES modules, Babylon.js9.31, GLB, node:test, воспроизводимые Python asset scripts, GitHub Pages.

## Историческая граница

Дворовые дома III–I тыс.: https://isac.uchicago.edu/sites/default/files/uploads/shared/docs/Publications/OIS/isacs16.pdf . Сырец/тростник: https://resources.metmuseum.org/resources/metpublications/pdf/Ancient_Near_Eastern_Art_The_Metropolitan_Museum_of_Art_Bulletin_v_41_no_4_Spring_1984.pdf . Круглые tholoi Халафа: https://doi.org/10.1080/00438243.1978.9979724 . Дом-улей на старте — явное игровое допущение, не доказанная типичная архитектура Шумера III тыс. Зелень ограниченная: контейнерные растения во дворах/у навесов; без сплошных влажных зарослей. Референсы пользователя изучены, изображения — художественные ориентиры.

## Выбранные игровые условия

Пять ульев — только для новой игры; существующие дома не заменяются. Популяция фауны не должна бесконтрольно расти или обнуляться при перезагрузке. Для кошек сохраняется ранее согласованный особый ввод чудом; для вредителей — отдельная механика. Для остальных наземных видов стартовая пара, постепенное воспроизводство и расселение. Смена визуальных домов не меняет прежние вместимость/стоимость обычных уровней.

Промежуточная проверка: 723/723 тестов до финального визуального уточнения фактуры стен; полная проверка повторяется при выявленных изменениях/ошибках. Подробные отчёты: HOUSES_RENEWAL, RESIDENT_ANATOMY, SKY_FLIGHT, WORKPLACE_CONTACTS (2026-10-23).

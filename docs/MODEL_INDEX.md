# Актуальный индекс моделей

Сгенерировано командой `node scripts/model-index.mjs`. Проверка: `node scripts/model-index.mjs --check`. Выпуск manifest: `festival-candles-tests-20261028-1`. Машиночитаемые данные: [model-index.json](model-index.json). Не редактировать таблицу вручную.

На диске / в manifest / в model-versions: **83 GLB**. Активных: **55**, резервов при ошибке: **9**, опций/студий: **5**, запасных без загрузки: **14**. Ошибок сверки: **0**.

«Активна» означает достижимый путь основного города, включая детали по событию/первому использованию и необязательные украшения с процедурным резервом. Это не число одновременно загруженных GLB. «Опция» означает API, выключенный main, или отдельную студию. «Запас» — отсутствует путь загрузки в проверенных исходниках; наличие файла в manifest само по себе не делает его активным.

Имена, байты и SHA256 проверяются по реальным GLB, manifest и model-versions; клипы читаются из GLB. Источники/лицензии берутся из встроенных asset.extras, для старых файлов — из ATTRIBUTION.md. Назначение и достижимость — явно проверяемая классификация в генераторе, а не вывод из имени файла. JSON хранит все места упоминаний, доказательство классификации и отпечатки исходников. Упоминание может быть неиспользуемой константой, поэтому само по себе не доказывает загрузку.

Ограничения: это консервативная статическая сверка локального JS, не выполнение сцены и не универсальный анализатор JavaScript. Динамические имена жителей и courtyard раскрыты отдельными адаптерами. Новый шаблон динамической загрузки требует обновить адаптер/классификацию. Источники подтверждают записанную атрибуцию, не новое юридическое разрешение. Standard остаётся Standard; отдельное разрешение пользователя записано в ATTRIBUTION.md, документ от автора в репозитории не приложен. У оригинальной геометрии проекта без указанной отдельной лицензии она честно помечена как неуказанная.

Исторические границы: индекс ничего не добавляет в игру. Шумерское основание одежды/материалов описано в [Met Museum](https://www.metmuseum.org/art/collection/search/325456) и [Penn Museum](https://www.penn.museum/sites/expedition/adaptation-and-change/); конкретные костюмы, виды зверей и ботаника остаются стилизацией. Свеча, поздние вавилонские чудеса, верблюд и исходная лодка Viking не становятся подтверждёнными шумерскими реконструкциями из-за присутствия в таблице. Чудесный сад явно фантастический.

Прежние датированные MODEL_INVENTORY_* — исторические снимки. Они не переписаны: числа 60/65 и прежние «основные» жители относятся к своим выпускам. Сейчас source-walk основной; human-native → sumer → resident — цепочки отказа (женская цепочка короче). Adobe GLB используется в художественном дворе; HOME_ASSET в buildings.js не загружается. Imported goose/старая стая сохранены без загрузки, sky-bird-single выключена в main, его небесные стаи процедурные.
